## Cómo descargar (solo lo que la persona tiene)

| Fuente | Cómo | Formato |
|---|---|---|
| Trello | Menú del tablero → Más → Imprimir y exportar → Exportar como JSON. Trae las últimas 1.000 acciones del tablero | JSON |
| EasyRetro | Engranaje de configuración del tablero → Export board → CSV | CSV |
| Google Slides | Archivo → Descargar → Texto sin formato (.txt). Las slides con diagramas importantes, además en PDF o PNG | .txt (+ PDF/PNG) |
| Miro | Seleccionar el marco → Exportar a CSV, más una imagen PNG del marco para no perder el orden visual. Solo exporta quien es dueño del tablero o tiene ese permiso | CSV + PNG |
| Google Docs (actas, documentos) | Archivo → Descargar → Markdown (.md); si no aparece, .docx | .md o .docx |
| Ficha antigua | Tal como esté | .md o .docx |
| Menti | Pestaña Results → Download → Spreadsheet (XLSX). Si no está disponible: PDF o captura de pantalla de la slide de resultados | Excel, PDF o PNG |

**Avisos:** mejor texto que imagen; un documento por tema, no carpetas completas. Todo se guarda en la carpeta de trabajo del estándar.

**Datos sensibles:** antes de subir un archivo, la persona revisa que no traiga información de personas beneficiarias, claves ni contraseñas. Si un dato así importa para el proceso, se describe sin incluirlo.
